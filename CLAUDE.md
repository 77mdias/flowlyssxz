# flowlyssxz — contexto do projeto

Repositório pessoal de estudo e produção de motion design para web (scroll, parallax, 3D/WebGL, interação).
A skill principal está em `skills/flowlyssxz/SKILL.md`; siga-a para qualquer pedido de decodificar referência,
adaptar para um nicho, construir com motion ou explicar ferramentas.

- Idioma: português do Brasil nas explicações e documentos; código e nomes técnicos em inglês.
- O dono do repo está aprendendo: termine entregas com "Por trás do código" (decisões + o que estudar).
- Biblioteca: `library/` (use `skills/flowlyssxz/scripts/library.py`). Nunca apague referências; mova para `_archive/` se pedido.
- Design systems de sites (URL → DESIGN.md + tokens + preview) ficam em `design-systems/<marca>-design-system/`; capturas em `captures/` (fora do git).
- Breakdowns em `library/refs/<id>/breakdown.md`, formato em `skills/flowlyssxz/references/breakdown-template.md`.
- Projetos construídos a partir das referências podem ficar em `playground/<nome>/` (um HTML único para estudos rápidos,
  ou Vite/Astro/Next para coisas maiores).
- Ambiente: Fedora Linux, Node e Python 3 disponíveis; ffmpeg necessário para a análise.
