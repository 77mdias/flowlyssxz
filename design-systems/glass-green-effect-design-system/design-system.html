Motion

Easing

Standardcubic-bezier(0.4, 0, 0.2, 1)

Every hover (.3s text, buttons, tags, borders · .4s cards, float, logo, bar · .6s image zoom) and the entrances (fadeIn 1s, slideUp .8s, scaleIn .6s).

Loopease-in-out

float 6s infinite · glow 2s alternate · ambientMove 8s / ambientMove2 10s alternate · pulse .6s.

Defaultease

Button sheen (left .5s), glow-border ::before opacity .3s, cursor size / colour .2s.

Cursor followlerp 0.22 (ring) · 0.28 (segments) per frame

interactions.js requestAnimationFrame loop; the dot snaps to the pointer.

Entrances

.animate-fade-in fadeIn 1s · translateY(20px) → 0, opacity 0 → 1
.animate-slide-up slideUp .8s · translateY(30px) → 0
.animate-scale-in scaleIn .6s · scale(.95) → 1

Staggered with .delay-100 … .delay-600 (animation-delay .1s steps: header, hero tags, title, lead, tag row, cards). The markup's .delay-700 / .delay-800 are Tailwind transition-delay utilities, so those pieces enter without an animation delay.
