Eight Shot

Landing de um app de câmera instantânea: papel creme, preto puro, uma família tipográfica, cartões quase brancos e três momentos de motion (polaroides que saem do celular, aparelho dobrável 3D preso à rolagem, reveals discretos).

Princípios

  • Papel, não tela: fundo creme #F9F3ED e cartões 1–3% mais claros ou mais frios; nunca branco puro como fundo de página.
  • Uma família, três pesos: Be Vietnam Pro 500 para texto, 600 para títulos, 700 para rótulos e títulos de cartão.
  • Cor só onde há significado: roxo e verde nos rótulos de seção, vermelho só em interação (foco, sublinhado, hover de ícone), lilás só no bloco de download.
  • O produto é a ilustração: mockups do app e polaroides fazem o papel de imagem; não há foto de banco nem ícone decorativo grande.
  • Motion em três volumes: entrada coreografada do hero, uma cena 3D presa à rolagem, e todo o resto em 240 ms ou 620 ms com a mesma curva.

Grau de confiança

  • cor exata (variáveis CSS do autor + estilos computados)
  • tipografia exata (família, pesos e clamp() lidos no CSS; tamanhos conferidos em 1440 e 390 px)
  • layout exato para desktop e mobile; breakpoints intermediários lidos no CSS, não vistos em tela
  • componentes repouso e hover medidos; foco e ativo lidos no CSS
  • motion exato para CSS e Web Animations; a cena 3D foi lida no código (duo.js) e vista em tela, não medida quadro a quadro
  • Nomes dos papéis (bg, surface-*, accent) são meus; a coluna de notas traz o nome original da variável no site.
  • text-muted é o preto a 50% de opacidade sobre o creme: 3,9:1, abaixo de AA para texto de 16 px. Mantido como no site; ao reutilizar, suba para 62% (≈ #5F5C5A, 5,9:1).
  • Estados que não aparecem em carga, rolagem e hover (menu mobile aberto, banner de consentimento) ficaram de fora.

Marca

The instant camera you’ll never run out of.

Eight Shot vende limite como prazer: 8 fotos por pacote, como filme de verdade. O visual sustenta isso com materiais de papel fotográfico (creme, sombras curtas, cantos pouco arredondados), polaroides reais como ilustração e uma interface que quase não tem cor própria, para que as fotos carreguem a cor.

Personalidade

  • Analógico sem nostalgia forçada ← papel creme e polaroides, mas tipografia grotesca limpa e 3D em tempo real
  • Contido ← uma família, preto puro, cor de acento usada em menos de 1% da área
  • Brincalhão nos detalhes ← sublinhado desenhado à mão, tira de cabine inclinada, ícones que giram 18° no hover
  • Tátil ← botões e selos sobem 2–3 px; cartões ganham sombra longa e o conteúdo se mexe, como objeto sobre a mesa

Voz e texto

  • Frases curtas, com ponto final, em duas ou três batidas: “Fold it shut. Shoot. Open it up.”
  • Números concretos no lugar de adjetivos: “just 8 shots”, “Four shots.”, “Nine frames. One memory.”
  • Rótulo de seção em caixa alta com 2–4 palavras antes do título: “SHOOT LIKE REAL FILM”, “PHOTO BOOTH”
  • CTA de uma palavra: “Download”. Sem “Get started”, sem “Learn more”.
  • Inglês, segunda pessoa, tom de amigo que explica um brinquedo, não de empresa de tecnologia

Imagem e ícones

  • Mockups do app em celular com moldura laranja-cobre, sempre retos ou com no máximo 4° de rotação
  • Polaroides com foto de pessoas em close, luz quente, borda branca ou colorida (amarelo, preto), sombra projetada suave
  • Um modelo 3D (celular dobrável) com material fosco e ambiente de estúdio neutro; sem cenário
  • Ícones de traço fino 16–20 px em preto; as únicas ilustrações são um rabisco de sublinhado em vermelho e as estrelas dos depoimentos
  • Faixa de quatro cores do logo (roxo, verde, lima, vermelho) reaparece como detalhe no topo dos mockups

Não fazer

  • Fundo branco puro ou cinza frio na página
  • Gradientes, vidro fosco ou brilho neon (o único blur é o dos dois botões-ícone fixos)
  • Segundo tipo de letra, itálico ou peso 800+ em títulos
  • Vermelho como cor de superfície ou de botão principal: ele é só de interação
  • Mais de um momento 3D ou parallax por página

const io = new IntersectionObserver((entries) => entries.forEach((e) => {
  if (!e.isIntersecting) return
  e.target.classList.add('is-in'); io.unobserve(e.target)

duo-foldrolagem · Three.js com cena presa (sticky)

Um celular dobrável 3D fica preso na tela por 2,2 alturas de viewport. A rolagem controla a abertura: fechado mostra a tela externa, aberto mostra a interna, e o texto ao lado troca junto. O aparelho inclina de leve na direção do mouse (ou do giroscópio no celular).

  • gatilho progresso = rolagem dentro de .duo__runway (320svh) com .duo__stage sticky de 100svh
  • alvo canvas.duo__canvas (WebGL2)
  • duração amarrada à rolagem
  • easing cubic in-out sobre o progresso + suavização 0.12 por quadro
  • feito com Three.js r186 · GLTFLoader · RoomEnvironment · import() preguiçoso
  • fonte duo.js
/* CSS: o 'pin' é só sticky */
.duo__runway { height: 320svh; }
.duo__stage  { position: sticky; top: 0; height: 100svh; }

// JS: rolagem → 0..1, suavizado, e só renderiza com o bloco na tela
const readProgress = () => {
  const span = runway.offsetHeight - stage.offsetHeight
  return Math.min(1, Math.max(0, -runway.getBoundingClientRect().top / span))
}
const ease = (t) => (t < .5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2)
function frame() {
  current += (readProgress() - current) * 0.12      // lerp
  const t = ease(current)
  fold((Math.PI / 2) * (1 - t))                      // dobra a malha
  holder.rotation.y = Math.PI - (Math.PI / 2) * t    // vira da capa para a tela interna
  lean.x += (input.x - lean.x) * 0.08                // mouse/giroscópio, ±0.2 rad
  renderer.render(scene, camera)
  if (running) requestAnimationFrame(frame)
}
